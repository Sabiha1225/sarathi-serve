# 2. --launch-skip 500: skips the first 500 kernel launches, which covers the trivial 
# 1-token prefill plus a handful of early decode iterations (warm-up, cache allocation 
# overhead) so you land in steady-state decode rather than startup noise.
# 3. --launch-count 1000: profiles the next 1000 kernel launches after the skip. 
# For a 32-layer model, one decode iteration is roughly a few hundred kernels 
# (attention + MLP + norms × 32 layers), so 1000 should comfortably span at least
